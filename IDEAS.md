# FLL Scoreboard — Ideas & Roadmap

## Features

- [ ] **Team detail panel** — click on a row to expand/open a modal showing all Done issues for that team (title, SP, date, repo, implementer)
- [ ] **Recently Completed feed** — panel with the last ~10 issues closed in chronological order: who implemented it, title, SP, when
- [ ] **Budget progress bars** — replace the Budget column number with a visual bar (green/red) showing available SP vs total implemented
- [ ] **Top performer of the week** — stat card highlighting the team with the most points in the last 7 days
- [ ] **Countdown to next update** — JS countdown showing minutes until the hourly workflow runs again
- [ ] **Velocity chart** — bar chart (non-cumulative) showing SP completed per week, to see if pace is increasing or dropping
- [ ] **Repo breakdown** — which repos each team is contributing to (backend, frontend, etc.) — `repo` field already available
- [ ] **Mini sparklines per row** — tiny inline trend line inside each table row showing that team's recent scoring evolution
